## 📖 পরিচিতি (Overview)

**সাতানীপাড়া সমাজকল্যাণ সংঘ** হলো একটি আধুনিক, মানবিক এবং বিশ্বাসযোগ্য নাগরিক প্ল্যাটফর্ম—যা এলাকার নাগরিক, প্রবাসী রেমিট্যান্স যোদ্ধা, রক্তদাতা এবং স্বেচ্ছাসেবকদের একটি সুসংগঠিত ডিজিটাল ছাতার নিচে যুক্ত করে।

প্ল্যাটফর্মটিতে রয়েছে **৩৫টি স্ক্রিন**, **৮টি সম্পূর্ণ ইউজার জার্নি (Flows)**, **৪টি ভিন্ন ভূমিকা (Roles)**, দ্বিভাষিক সহায়তা (**বাংলা ও ইংরেজি**), **লাইট ও ডার্ক থিম** এবং **সম্পূর্ণ রেসপন্সিভ মোবাইল আর্কিটেকচার**।

## 🎨 ক্রিয়েটিভ ডিরেকশন ডি (Direction D Architecture)

Direction D তিনটি পরিপূরক নীতির সমন্বয়ে নির্মিত:
1. **প্রিমিয়াম ডিজিটাল প্রোডাক্ট (Premium Digital Product):** অ্যাপল-অনুপ্রাণিত সূক্ষ্ম ইন্টারঅ্যাকশন, ক্লিয়ার স্পেসিং, সুসংহত কার্ড স্ট্রাকচার ও শূন্য ভিজ্যুয়াল নয়েজ।
2. **আন্তর্জাতিক এডিটোরিয়াল ডিজাইন (International Editorial Design):** অ্যাসিমেট্রিক লেআউট, বড় টাইপোগ্রাফিক বৈপরীত্য, ডকুমেন্টারি ফটোগ্রাফি ক্রপ, মাইলফলক লেজার ও গভীর বিষয়বস্তু প্রবাহ।
3. **বাঙালি সাংস্কৃতিক ঐতিহ্য (Bengali Identity):** তিরো বাংলা (`Tiro Bangla`) ও অনেক বাংলা (`Anek Bangla`) ফন্টে নিহিত ঐতিহ্যমণ্ডিত আবহ, শতভাগ শুদ্ধ যুক্তাক্ষর এবং স্থানীয় প্রবাসী-কেন্দ্রিক মানবসেবা।

- **কালার প্যালেট (Refined Palette):**
  - **Refined Forest Green (#0B2E1F):** স্থায়িত্ব, নাগরিক প্রতিষ্ঠান ও আস্থা।
  - **Restrained Heritage Gold (#C9A227):** মর্যাদা, ঐতিহ্য ও প্রাতিষ্ঠানিক রৌপ্যজয়ন্তী স্বীকৃতি।
  - **Warm Ivory (#FAF7EE):** উষ্ণ, পাঠযোগ্য এবং নন-ক্লিনিক্যাল আর্ট পেপার ব্যাকগ্রাউন্ড।
  - **Sophisticated Neutral Surfaces:** `#FFFFFF` (Card), `#F4EFE6` (Raised), `#0A140F` (Dark Canvas).

## ⚙️ প্রোটোটাইপ HUD সিস্টেম (Interactive HUD)

প্রতিটি পৃষ্ঠার নিচে ডানে একটি ভাসমান **⚙️ HUD মেনু** বোতাম রয়েছে। এটি দিয়ে আপনি এক ক্লিকেই:
1. **৩৫টি স্ক্রিনের যেকোনোটিতে সরাসরি যেতে পারবেন**।
2. **ভূমিকা (Role) পরিবর্তন করতে পারবেন:**
   - `Public Guest` (সাধারণ দর্শনার্থী)
   - `Member` (প্রবাসী/স্থানীয় সদস্য)
   - `Expatriate Helper` (প্রবাসী সহায়ক — কেবল আবেদন পরিচালনা)
   - `Super Admin` (সর্বোচ্চ প্রশাসনিক ক্ষমতা)
3. **৮টি পূর্ণাঙ্গ ফ্লো টেস্ট করতে পারবেন (F-01 থেকে F-08)**।
4. **বাংলা / ইংরেজি (BN/EN) ভাষা পাল্টাতে পারবেন**।
5. **লাইট / ডার্ক মোড (Light/Dark Theme) পরিবর্তন করতে পারবেন**।
6. **মক ডেটাবেস প্রাথমিক অবস্থায় রিসেট করতে পারবেন**।

## 🔄 ইন্টারেক্টিভ ইউজার জার্নি (Interactive Journeys F-01 to F-08)

1. **F-01: জরুরি রক্তদাতা অনুসন্ধান (Public Flow)**  
   রক্তের গ্রুপ, ইউনিয়ন ও ওয়ার্ড ফিল্টার করে তাৎক্ষণিক ফোন বা হোয়াটসঅ্যাপ কল ও ডোনার কনসেন্ট যাচাই।
2. **F-02: প্রবাসী সহায়তা আবেদন (৩ ধাপের উইজার্ড)**  
   সেবা নির্বাচন → বিস্তারিত তথ্য ও এটাচমেন্ট → মোবাইল ও গোপনীয়তা সম্মতি প্রদান করে তাৎক্ষণিক ট্র্যাকিং কোড অর্জন।
3. **F-03: সহায়ক আবেদন গ্রহণ ও পরিচালনা (Helper Flow)**  
   নতুন আবেদনের ব্রাউজার পুশ নোটিফিকেশন → দায়িত্ব গ্রহণ → স্ট্যাটাস আপডেট ও মন্তব্য যুক্ত করা।
4. **F-04: সদস্য নিবন্ধন ও প্রশাসনিক অনুমোদন**  
   নতুন সদস্য আবেদন ফরম → এডমিন প্যানেলে পেন্ডিং তালিকা → ভেরিফিকেশন ও এক ক্লিকে অনুমোদন।
5. **F-05: নতুন ইউজার তৈরি ও রোল অ্যাসাইন**  
   সুপার এডমিন কর্তৃক সহকারী বা কর্মকর্তা যুক্তকরণ এবং অনুমতি নির্ধারণ।
6. **F-06: জরুরি নোটিশ প্রকাশ ও টিকার আপডেট**  
   নতুন নোটিশ তৈরি → হোমপেজের স্ক্রলিং ব্রেকিং টিকারে তাৎক্ষণিক প্রতিফলন।
7. **F-07: আর্থিক হিসাব এন্ট্রি ও স্বচ্ছতা অডিট**  
   আয়/ব্যয় ভাউচার যুক্তকরণ → জনস্বার্থে পাবলিক ট্রানস্প্যারেন্সি চার্ট আপডেট।
8. **F-08: ভুলে যাওয়া পাসওয়ার্ড ম্যানুয়াল রিকভারি**  
   ওটিপি জটিলতা ছাড়া সিকিউরিটি প্রশ্নের মাধ্যমে সহজ ও নির্ভরযোগ্য পাসওয়ার্ড পুনরুদ্ধার।

## 💻 লোকাল ডেভেলপমেন্ট (Local Setup)

কোনো ভারী ডিপেনডেন্সি নেই—সম্পূর্ণ ভ্যানিলা HTML, CSS ও JavaScript!

```bash
# ক্লোন করুন
git clone https://github.com/mefahim/sotanipara-community.git
cd sotanipara-community

# লোকাল সার্ভার রান করুন (Node.js)
npm start
# অথবা:
node server.js

# ব্রাউজারে খুলুন:
# http://localhost:3000/
```
